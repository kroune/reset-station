# Reset Station

Одна команда для сброса задач в папке `X` на Windows без закрытия VS Code.

**Сайт с кнопкой копирования:** <https://kroune.github.io/reset-station/>

## Использование

1. Откройте папку `X` в VS Code.
2. Откройте встроенный терминал (`Ctrl` + `` ` ``).
3. Убедитесь, что текущий путь заканчивается на `\X`.
4. Вставьте команду в PowerShell или CMD и нажмите Enter:

```powershell
powershell -NoLogo -NoProfile -ExecutionPolicy Bypass -Command "Invoke-RestMethod 'https://raw.githubusercontent.com/kroune/reset-station/main/reset-x.ps1' | Invoke-Expression"
```

Команда скачивает и выполняет [`reset-x.ps1`](reset-x.ps1). Скрипт:

- проверяет, что текущая папка называется `X`;
- скачивает ZIP ветки `master` из `https://git.cu3rd.ru/cu3rd/aircul-cuya`;
- сначала распаковывает архив во временную папку;
- полностью очищает содержимое `X`, включая скрытые файлы, но сохраняет саму папку;
- копирует в `X` содержимое репозитория без дополнительной вложенной папки;
- удаляет временные файлы.

Git, права администратора и перезапуск VS Code не требуются. Нужны Windows 10/11 со встроенным Windows PowerShell 5.1 и доступ в интернет.

> **Внимание:** несохранённые изменения и все другие файлы внутри `X` будут удалены. При ошибке скачивания или распаковки очистка не начинается.

## Публикация
