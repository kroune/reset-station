Reset Station

Очищает содержимое открытой папки X и загружает туда свежие задачи. Сама папка и VS Code остаются открытыми.

Как запустить

  1. Откройте папку X в VS Code.
  2. Выберите Терминал → Создать терминал или нажмите Ctrl + `.
  3. Убедитесь, что путь в терминале заканчивается на \X.
  4. Скопируйте команду ниже, вставьте её в терминал и нажмите Enter.

Команда для PowerShell или CMD

powershell -NoLogo -NoProfile -ExecutionPolicy Bypass -Command "Invoke-RestMethod 'https://raw.githubusercontent.com/kroune/reset-station/main/reset-x.ps1' | Invoke-Expression"

Важно: команда полностью удаляет содержимое текущей папки, включая скрытые файлы. Запускайте её только внутри X. Скрипт дополнительно проверяет имя папки и откажется работать в другом месте. Права администратора и установленный Git не нужны.

Что произойдёт

  1. Свежий архив задач скачается и распакуется во временную папку.
  2. Только после успешной распаковки очистится содержимое X.
  3. Новые задачи будут скопированы в X, временные файлы удалятся.

Если скачивание не удалось, текущие задачи не будут удалены. После успешного сброса появится сообщение «Готово! Папка X содержит свежие задачи».
